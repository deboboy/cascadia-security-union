# 90-Day Launch Plan

## Goal

Launch a credible founding cohort of Seattle-area security leaders with a repeatable monthly rhythm and a clear value proposition.

## Day 0-30: Foundation

Deliverables:
- Finalize charter and community name
- Recruit Steering Committee (5-7 founding leaders)
- Define membership criteria and invitation process
- Select collaboration platform and event stack

Actions:
- Conduct 12-15 founder interviews to validate priorities
- Build founding member prospect list (30-40 candidates)
- Draft first 3 months of event topics and hosts

Exit criteria:
- Steering committee confirmed
- Initial event calendar approved
- Top 20 founding prospects identified

## Day 31-60: Recruitment and Positioning

Deliverables:
- Publish microsite and invitation packet
- Open member application or invitation flow
- Secure first venue partner in Seattle area

Actions:
- Personal outreach to target members (1:1 invitations)
- Host a virtual preview session (45-60 minutes)
- Gather topic rankings from prospects

Exit criteria:
- 12+ founding members committed
- First in-person and first virtual events fully scheduled

## Day 61-90: Launch and Iterate

Deliverables:
- Host first in-person roundtable
- Host first online working session
- Publish first-quarter program calendar

Actions:
- Run post-event feedback pulse within 24 hours
- Tune format based on participation data
- Confirm sponsorship terms (if needed) under policy guardrails

Exit criteria:
- 2 successful launch events completed
- 20+ active members in network
- Q2 roadmap ready

## Risks and Mitigations

1. Low initial trust
- Mitigation: private invite-only start, strong confidentiality policy, founder-led moderation

2. Vendor influence concerns
- Mitigation: explicit sponsor boundaries, agenda independence, no sales presentations in peer core

3. Inconsistent attendance
- Mitigation: strict relevance, curated topics, predictable cadence, high-quality facilitation

## Suggested Initial Budget Categories

- Venue and catering
- Community operations/facilitation
- Digital platform tooling
- Brand and communication assets
- Recording/editing (only for approved external content)

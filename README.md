# Cascadia Security Leadership Circle

Seattle-area peer community for CISOs, CSOs, and security executives — with a static recruiting site and planning docs.

## Edit the site

All public copy lives in one file:

```
content.js
```

Change headlines, CTA labels, program items, themes, criteria, FAQ, contact email, or footer there. Refresh the browser to see updates. Leave the object keys and array structure as-is unless you are adding or removing list items.

Layout and styling stay in `index.html` and `styles.css`. Behavior stays in `script.js`.

## Local preview

```bash
python3 -m http.server 8080
```

Open [http://localhost:8080](http://localhost:8080).
